## 住宅 IP 才是 SixtyNet 的定价核心

同样 2 核 2G / 40G NVMe / 5TB 流量，LAX-STARTER 是 $200/年，Residential-STARTER 是 $260/年，差价 $60 买的是一个住宅属性的 IPv4。IRVINE-PRO-STARTER 再加 $90，把线路换成标称的 AS9929。

## LAX 系列便宜，但别把「Premium Network」当成 CN2

LAX-STARTER 页面写的是 2G Premium Network，这个词很容易让人以为走的是 CN2 或者 9929。第三方测速平台在 2026 年 11 月 14 日记录的数据显示，这台 $200/年 的机型配置为 2 颗 AMD EPYC-Rome、1.9GB 实际可用内存、39GB 磁盘、5TB 月流量，国内三网回程走的是电信 163、联通 4837、移动 CMI。

延迟中位数参考：北京电信 176ms、联通 174ms、移动 195ms；上海电信 142ms；广东移动 179ms；四川移动 223ms。这个水平属于普通美西国际线，和 CN2 GIA、9929 不是一个量级。

要中国优化，往上得选 IRVINE-PRO（标称 AS9929），或者那个 $2500/年 的 China Unicom-Premium。后者提供 100M 基础带宽、3 倍突发、95 计费，还带免费 BGP 会话和有限的技术支持，面向的是要自己播 IP 段的业务方，个人买家看了价格就知道不是给自己准备的。

## 下单前必须确认的五件事

1. **币种与税费**。官网标 USD，结账页确认最终扣款金额、支付方式以及是否有额外税费。
2. **端口**。Residential 和 IRVINE-PRO 全系不开放 80 和 443，有建站需求直接排除这两组。
3. **退款**。只有 IRVINE-PRO 系列在页面上写了退款政策，且只退到网站余额；其他系列页面未标注退款条款，下单前问清楚。
4. **续费**。官网没有单列续费价，年付到期按当时标价执行，别按促销价做三年预算。
5. **IP 属性会漂移**。住宅 IP 的数据库判定随时间变化，今天测出来是家宽，几个月后可能变。这类资源适合按年评估，不适合一次性押长期。
